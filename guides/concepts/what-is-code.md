# What Is Code (and What Is Programming)?

## The Simple Version

Code is a set of instructions written in a language that computers can understand. Programming is the act of writing those instructions.

When you write code, you're telling the computer what to do — step by step, very precisely. Computers are fast but literal: they do exactly what you tell them, nothing more, nothing less.

## Why Do We Need Special Languages?

Computers don't understand English (not directly, anyway). They understand electrical signals — ones and zeros. But writing in ones and zeros would be impossibly tedious, so people created **programming languages** as a middle ground: readable enough for humans, precise enough for computers.

```javascript
if (temperature > 30) {
  showMessage("It's hot outside!");
}
```

You can probably guess what this does even if you've never coded. That's the point of modern programming languages — they're designed to be somewhat readable.

## Common Programming Languages

There are hundreds of languages, each with strengths. For building websites, you mainly need:

| Language | Used for | Notes |
|----------|---------|-------|
| **HTML** | Structure of web pages | Not technically "programming" — it's a markup language. But it's essential. |
| **CSS** | Visual styling | Also not programming. It describes how things look. |
| **JavaScript** | Interactive behavior, website logic | The programming language of the web. Runs in browsers. |
| **TypeScript** | Same as JavaScript with added safety | JavaScript with extra guardrails. Popular in larger projects. |
| **Python** | Servers, data science, automation | Easy to learn, very popular. Not used in browsers. |

For your first website, you'll mostly work with HTML, CSS, and JavaScript. Your AI assistant writes the code — you describe what you want.

## What Does "Writing Code" Actually Look Like?

You open a text file, type instructions in a programming language, and save it. That's it. Code is just text in files.

The magic happens when something *runs* that code:
- A **browser** runs HTML, CSS, and JavaScript
- **Node.js** runs JavaScript outside a browser (on your computer or a server)
- **Python** runs Python files

Your AI coding assistant creates these files for you and runs them. Over time, you'll start reading the code it writes, understanding it, and eventually tweaking it yourself. That's how most people learn.

## Do You Need to Learn to Code?

Not to get started. The AI handles it. But you'll naturally pick things up as you go:

- First, you'll recognize patterns ("that `<div>` thing is a container")
- Then, you'll understand what the AI is doing ("it's adding a CSS class for spacing")
- Eventually, you'll make small edits yourself ("I'll just change this color from blue to green")
- Someday, you might write features from scratch

There's no pressure to reach any particular level. Use the AI as much or as little as you want. The goal is to build something, not to pass a programming exam.
