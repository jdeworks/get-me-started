# What Is an LLM (and How Can It Help You Code)?

When you talk to ChatGPT, Claude, or Gemini, you're talking to a **Large Language Model** — or LLM for short.

## The Simple Version

An LLM is a program that has read enormous amounts of text — books, websites, code, conversations — and learned patterns from all of it. When you type something, it predicts what a helpful response would look like, word by word.

It doesn't "think" the way you do. It doesn't have a brain or consciousness. But it's very good at producing text that's useful, including code.

## Why It Can Help You Build a Website

Programming is a language — a very specific, structured one. LLMs are great at languages. They've seen millions of code examples, tutorials, documentation pages, and Stack Overflow answers. So when you say "make me a blue navigation bar," the LLM knows:

- What HTML structure a navigation bar needs
- What CSS makes it blue
- What JavaScript makes it interactive
- Common patterns and best practices

It's like having a very well-read assistant who has studied every tutorial ever written. It doesn't always get things right on the first try, but you can talk to it, correct it, and guide it — just like working with another person.

## The Different Kinds of AI Tools You'll See

| Type | What it does | Examples |
|------|-------------|---------|
| **Chat AI** | You type, it responds. Can explain things, write code, answer questions. Cannot run code or touch files on your computer. | ChatGPT, Claude (web), Gemini |
| **AI Coding Assistant** | Same conversation ability, but can also create files, run commands, and execute code on your computer. | OpenCode, Claude Code, Cursor, GitHub Copilot |

This is why the get-me-started guide has two phases: first you talk to a chat AI to set things up (because you already have one), then you switch to an AI coding assistant that can actually build things.

## What It's Good At

- Writing code from a description ("make a contact form with email validation")
- Explaining what existing code does
- Fixing bugs when you describe the problem
- Suggesting designs and layouts
- Answering "how do I...?" questions about programming

## What It's Not Good At

- Making business decisions for you (it doesn't know your audience)
- Guaranteeing security (always review suggestions for sensitive features)
- Knowing what you want without you telling it (be specific!)
- Always being right (it can confidently produce incorrect code — test things)

## The "Paste-Back" Pattern

When you're using a chat AI (like ChatGPT) that can't run code, you work in a loop:

1. You describe what you want
2. The AI gives you a command or code
3. You run it on your computer and paste the result back
4. The AI checks if it worked and gives you the next step

This is slower than an AI coding assistant (which does steps 2-4 automatically), but it works. And it teaches you more, because you see every step happening.

## Do You Need to Understand How LLMs Work?

No. You don't need to understand how a car engine works to drive. Knowing the basics helps you work with AI more effectively — like knowing that being specific gets better results, or that the AI doesn't remember previous conversations unless you remind it. But you can start building right now with just the knowledge that: you describe what you want, and the AI helps you make it.
