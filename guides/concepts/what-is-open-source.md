# What Is Open Source (and Why Does It Matter)?

## The Simple Version

**Open source** means the code is public. Anyone can read it, use it, learn from it, and suggest improvements. It's the opposite of closed/proprietary software, where the code is hidden and controlled by one company.

All the tools in the get-me-started ecosystem are open source. You can see exactly how they work.

## Why It Matters to You

### It's free

Open source software is free to use. No trial periods, no subscriptions, no "upgrade to unlock." OpenCode, Node.js, Docker, Git, VS Code — all free, all open source.

### You're not locked in

If a tool stops being maintained or takes a direction you don't like, someone else can fork it (make a copy) and keep it going. Your work doesn't depend on one company staying in business.

### You can learn from it

Every open source project's code is readable. The tools helping you build your website? You can read their source code. This is one of the best ways to learn programming — by reading real code that real people use.

### You can contribute

Found a bug? You can report it. Have an improvement? You can suggest it. This is how open source software gets better — thousands of people each contributing a little bit.

## How Open Source Licensing Works

Open source doesn't mean "no rules." Each project has a **license** that says what you can and can't do. The most common ones:

| License | What it means |
|---------|--------------|
| **MIT** | Do whatever you want. Just include the copyright notice. (This is what get-me-started uses.) |
| **Apache 2.0** | Similar to MIT, with some extra patent protections. |
| **GPL** | You can use and modify it, but if you share your modified version, you must also share your code. |

For building your website: you're fine using any open source tool. The licenses are designed to be permissive for this kind of use.

## The Bigger Picture

Most of the internet runs on open source. Linux (operating system), Node.js (web platform), PostgreSQL (database), React (UI framework), Nginx (web server) — all open source. Companies like Google, Netflix, and Microsoft both use and contribute to open source projects.

By building your website with these tools, you're using the same infrastructure that powers the biggest sites in the world. And if you ever want to give back, the door is always open.
