Set up GitHub

Save your work and put your website online, for free

What is GitHub? It's a free website where your project files are stored safely online. It's like a backup that also lets you publish your website for the world to see. Millions of people use it. It's the standard.

This step is optional. You can start building your website without GitHub. But we recommend setting it up because:
  • Free backup: your work is saved online, even if something happens to your computer
  • Free hosting: you can publish simple websitesA website that shows the same pages to everyone, like a digital brochure for your shop, a portfolio, or a blog. These work great on GitHub Pages (free). If you later need features like user accounts, payments, or a database, the AI will help you find affordable hosting for that. for the world to see at yourname.github.io
  • Easy sharing: send anyone a link to see your code or your site

This takes about 5 minutes. You can also come back and do this later.

Step 1: Create a free account

1

Go to github.com/signup

2

Enter your email address

Use any email you have. You can change it later.

3

Create a password

4

Choose a username

This will be part of your website's free address (like yourname.github.io). Pick something short and simple.

5

Complete the verification puzzle and click "Create account"

6

Check your email for a verification code and enter it

That's it, you have a GitHub account!

Step 2: Connect your computer to GitHub

We need to create a secure "key" on your computer. Think of it like a digital ID card that lets your computer prove who it is to GitHub, without typing a password every time.

Pick your computer type, then run the command shown. It installs Git (if needed) and creates your key in one go:

Step A: Open PowerShell (press the Windows key, type "PowerShell", click it) and paste this to install Git and create your key:

winget install --id Git.Git --accept-source-agreements --accept-package-agreements; ssh-keygen -t ed25519 -N '""' -f "$env:USERPROFILE\.ssh\id_ed25519" -q

This installs Git (a tool for saving and sharing your code) and creates a secure key. If Git is already installed, it skips that part. The key is saved in a hidden folder on your computer.

Step B: Now copy your key by pasting this:

type $env:USERPROFILE\.ssh\id_ed25519.pub

Select the entire output (starts with ssh-ed25519) and copy it.

Step A: Open Terminal (press Cmd+Space, type "Terminal", press Enter) and paste this:

ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519 -q; cat ~/.ssh/id_ed25519.pub | pbcopy

This creates a secure key and copies it to your clipboard automatically. Git is already included with your Mac's developer tools. If you already have a key, this won't overwrite it.

Your key is now on your clipboard. Just paste it in the next step.

Step A: Open a terminal (Ctrl+Alt+T) and paste this to install Git and create your key:

sudo apt install -y git 2>/dev/null || sudo dnf install -y git 2>/dev/null; ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519 -q

This installs Git (if needed) and creates a secure key. May ask for your password.

Step B: Copy your key:

cat ~/.ssh/id_ed25519.pub

Select the entire output (starts with ssh-ed25519) and copy it.

Add it to GitHub

1

Go to github.com/settings/ssh/new

This is GitHub's "SSH keys" settings page. You may need to log in first.

2

In the "Title" field, type a name for your computer (e.g., "My Laptop" or "Home PC")

This is just a label so you can remember which computer this key belongs to.

3

In the "Key" field, paste the key you copied above

It should start with ssh-ed25519 followed by a long string of letters and numbers.

4

Click the green "Add SSH key" button

5

GitHub may ask you to confirm your password. Enter it and confirm.

Done! Your computer is now connected to GitHub. The AI coding tool will be able to save your work and publish your website automatically.
