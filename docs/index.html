Step 2 — Download the setup helper

This script will install the tools you need: Git and Docker Desktop. Everything runs inside a safe, isolated space on your computer.

Download setup for Windows setup-windows.ps1 — about 4 KB

How to run it:

1

Find the downloaded file (usually in your Downloads folder)

2

Right-click the file and choose "Run with PowerShell"

3

If Windows asks "Do you want to allow this app to make changes?" — click Yes. This is normal — the script needs permission to install programs.

4

Wait for it to finish. You'll see a message saying "All done!"

This script will install the tools you need: Node.js and OpenCode (your AI coding assistant). Takes about 5 minutes.

Download setup for Mac setup-mac.command — about 3 KB

How to run it:

1

Find the downloaded file in your Downloads folder

2

Double-click the file. A Terminal window will open.

3

If macOS says "can't be opened because it's from an unidentified developer":

  • Right-click (or Control-click) the file
  • Choose "Open" from the menu
  • Click "Open" again in the dialog
4

It may ask for your password — this is your computer's login password. Type it and press Enter. (You won't see the characters as you type — that's normal.)

5

Wait for it to finish. You'll see "All done!"

This script will install the tools you need: Node.js and OpenCode (your AI coding assistant). Takes about 5 minutes.

Download setup for Linux setup-linux.sh — about 3 KB

How to run it:

1

Open a terminal (press Ctrl + Alt + T on most systems)

2

Type these two lines and press Enter after each:

chmod +x ~/Downloads/setup-linux.sh
~/Downloads/setup-linux.sh
3

It may ask for your password. Type it and press Enter.

4

Wait for it to finish. You'll see "All done!"

Step 3 — Go back to your AI chat

Once the setup is done, go back to your AI chatbot (ChatGPT, Claude, Gemini — wherever you started) and tell it:

The AI will guide you from here to build your website.

Something went wrong?

Don't worry — this happens sometimes. Copy the error message you see and paste it back to your AI chatbot. It can help you fix it.

Common issues:

  • Windows says "Windows protected your PC" — Click "More info", then "Run anyway". This appears because the script isn't signed by a big company. It's safe.
  • Mac says the file "can't be opened" — Right-click the file, choose "Open", then click "Open" again.
  • "Permission denied" — On Mac/Linux, the script may need your password. On Windows, right-click and choose "Run as Administrator".
