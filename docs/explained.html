What the setup scripts do

Every step, explained in plain language

We want you to feel safe running these scripts. Below is a plain-language explanation of every single thing each script does, and why. No surprises.

You can also read the scripts yourself — they're plain text files. Right-click the downloaded file and open it with any text editor (Notepad, TextEdit, etc.) to see exactly what's inside.

Which script did you download?

Windows — Safe install (Docker)

This script sets up everything inside a protected space on your computer.

Step 1: Check for winget

The script checks if your computer has "winget" — a built-in tool that Windows uses to install programs (like an app store, but from the command line).
Why: All the programs we need can be installed through winget. If it's missing, your Windows may need an update.

Step 2: Install Git

The script checks if Git is already on your computer. If not, it installs it using winget.
Why: Git is a tool that downloads project files from the internet. We need it to get the AI coding setup files. It's free, used by millions of developers, and completely safe.
If Git is already installed, this step is skipped entirely.

Step 3: Install Docker Desktop

The script checks if Docker is already installed. If not, it installs Docker Desktop using winget. This is the largest download (~500 MB).
Why: Docker creates isolated spaces (called "containers") on your computer. Your AI coding tool will run inside one of these containers. This means nothing gets mixed into your regular system — it's the "safe" part of the safe install.
If Docker is already installed, this step is skipped. After installing, you may need to restart your computer once for Docker to fully activate.

Step 4: Create an SSH key

The script checks if you already have an SSH key. If not, it creates one — a pair of files in a hidden .ssh folder on your computer.
Why: An SSH key is like a digital ID card. It lets your computer prove who it is to GitHub without typing a password every time. The key stays on your computer and is never sent anywhere — only the "public" half gets shared with GitHub (you'll do that in the next step).
Skipped if a key already exists. The key is NOT a password — it's a randomly generated pair of files that only your computer has.

Step 5: Create a Projects folder

The script creates a folder at C:\Projects.
Why: This is where your website files will live. It's just a regular folder — you can open it in File Explorer like any other folder.
If the folder already exists, this step is skipped.

Step 6: Download agent-sandbox

The script uses Git to download the "agent-sandbox" project files into C:\Projects\agent-sandbox.
Why: Agent-sandbox is the tool that sets up your AI coding environment inside Docker. It comes with ready-made configurations so you don't have to set anything up manually.
If the folder already exists, this step is skipped.

Done!

The script shows "All done!" and waits for you to press Enter.
What you have now: Git, Docker Desktop, and the agent-sandbox files — everything needed for your AI coding assistant to run in a safe, isolated space.
See the actual script code with annotations

You can also open the downloaded file in any text editor (like Notepad) to read it yourself.

# Allow this script to run in the current session
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

# Check if "winget" exists — it's Windows' built-in app installer
# If missing, your Windows may need an update
$hasWinget = Get-Command winget -ErrorAction SilentlyContinue

# Install Git (a tool for downloading project files)
# Skipped if already installed
winget install --id Git.Git

# Install Docker Desktop (creates isolated containers)
# This is the largest download (~500 MB)
# Skipped if already installed
winget install --id Docker.DockerDesktop

# Create an SSH key (a digital ID for your computer)
# Skipped if one already exists
ssh-keygen -t ed25519 -f $sshKeyPath -N '""' -q

# Create C:\Projects folder (where your websites live)
# Skipped if it already exists
New-Item -ItemType Directory -Path "C:\Projects"

# Download agent-sandbox (the AI coding environment setup)
git clone https://github.com/jdeworks/agent-sandbox.git C:\Projects\agent-sandbox

# Print your SSH key so you can copy it to GitHub

Windows — Quick install

This script installs the AI coding tools directly on your computer.

Step 1: Check for winget

Same as the safe install — checks if Windows' built-in program installer is available.
Why: We use it to install the programs below.

Step 2: Install Git

Checks for Git, installs it if missing.
Why: Git downloads project files from the internet. Free, safe, used by millions.
Skipped if already installed.

Step 3: Install Node.js

Checks for Node.js, installs the latest stable version if missing.
Why: Node.js is the engine that runs website code on your computer during development. It's what makes it possible to preview your website locally. Used by Netflix, Uber, NASA, and millions of developers.
Skipped if already installed.

Step 4: Install OpenCode

Checks for OpenCode, installs it using Node.js's package manager (npm) if missing.
Why: OpenCode is the free AI coding assistant that builds your website. You describe what you want in plain words, and it writes the code for you.
Skipped if already installed.

Step 4: Create an SSH key

Creates a secure key pair so your computer can talk to GitHub.
Why: Like a digital ID card — lets your computer prove who it is without typing a password every time. The key stays on your computer.
Skipped if a key already exists.

Step 5: Create a Projects folder

Creates C:\Projects.
Why: Where your website files will live. Just a regular folder.
Skipped if it already exists.

Done!

The script shows "All done!" and prints your SSH key.
What you have now: Git, Node.js, OpenCode, and an SSH key — everything needed to start building.

Mac setup

This script installs the tools you need to build websites with AI on your Mac.

Step 1: Install developer tools (includes Git)

The script checks if Apple's "Command Line Tools" are installed. If not, a popup will appear asking you to install them.
Why: These tools include Git (for downloading project files) and other essentials that many programs need. They come directly from Apple and are completely safe.
Skipped if already installed. The popup comes from Apple, not from our script.

Step 2: Install Node.js

Checks for Node.js. If missing, installs it using Homebrew (a popular Mac tool installer). If Homebrew isn't installed either, it installs that first.
Why: Node.js is the engine that runs website code on your computer. Homebrew is the standard way to install developer tools on a Mac — it's free, open source, and trusted by millions of Mac users.
Skipped if already installed. Homebrew installation may ask for your password — that's your Mac login password, needed because it installs into a system folder.

Step 3: Install OpenCode

Checks for OpenCode, installs it via Homebrew or a direct download if missing.
Why: OpenCode is the free AI coding assistant. You describe what you want, it writes the code.
Skipped if already installed.

Step 4: Create an SSH key

Creates a secure key pair in a hidden .ssh folder on your Mac.
Why: Like a digital ID card — lets your computer prove who it is to GitHub without typing a password every time. Only the "public" half gets shared.
Skipped if a key already exists.

Step 5: Create a Projects folder

Creates a Projects folder in your home directory (~/Projects).
Why: Where your website files will live. You can find it in Finder under your home folder.
Skipped if it already exists.

Done!

The script shows "All done!" and prints your SSH key.
What you have now: Developer tools, Node.js, OpenCode, and an SSH key — everything needed to start building.

Linux setup

This script installs the tools you need to build websites with AI on Linux.

Step 1: Install Git

Checks for Git, installs it with your system's package manager (apt, dnf, or pacman) if missing.
Why: Git downloads project files from the internet. It may ask for your password because installing system packages requires admin permission.
Skipped if already installed.

Step 2: Install Node.js

Checks for Node.js. If missing, installs "nvm" (Node Version Manager) first, then uses nvm to install Node.js.
Why: Node.js runs website code on your computer. nvm is the recommended way to install it on Linux because it doesn't require admin permission and lets you manage versions easily.
Skipped if already installed.

Step 3: Install OpenCode

Checks for OpenCode, downloads and installs it if missing.
Why: The free AI coding assistant that builds your website.
Skipped if already installed.

Step 4: Create an SSH key

Creates a secure key pair so your computer can talk to GitHub.
Why: Like a digital ID card for your computer. Only the "public" half gets shared with GitHub.
Skipped if a key already exists.

Step 5: Create a Projects folder

Creates ~/Projects.
Why: Where your website files will live.
Skipped if it already exists.

Done!

The script shows "All done!" and prints your SSH key.
What you have now: Git, Node.js, OpenCode, and an SSH key — everything needed to start building.
See the actual script code with annotations 
# Install Git (downloads project files)
# Uses your system's package manager (apt, dnf, or pacman)
# May ask for your password
# Skipped if already installed
sudo apt install -y git

# Install Node.js via nvm (Node Version Manager)

# Skipped if already installed

nvm install --lts

# Install OpenCode (the AI that writes code for you)

# Create ~/Projects folder
# Skipped if it already exists
