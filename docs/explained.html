What the setup scripts do

Every step, explained in plain language

We want you to feel safe running these scripts. No surprises, no hidden steps.

You can verify this yourself: right-click the downloaded file and open it with any text editor (Notepad on Windows, TextEdit on Mac). Every line has a comment explaining what it does. What you see below matches the file exactly.

Windows — Safe install (Docker)

Plain-language explanation

1. Check for winget

Checks if Windows' built-in app installer is available. If missing, your Windows may need an update.

2. Install Git

Installs Git — a tool for downloading project files from the internet. Free, safe, used by millions.

Skipped if already installed.

3. Install Docker Desktop

Installs Docker — creates isolated spaces ("containers") where your AI tools run. This is the largest download (~500 MB). Nothing else on your system is affected.

Skipped if already installed. May need a restart.

4. Create SSH key

Creates a secure key pair — like a digital ID card for your computer. Lets it talk to GitHub without a password. The key stays on your machine.

Skipped if one exists.

5. Create Projects folder + download agent-sandbox

Creates C:\Projects (where your websites live) and downloads agent-sandbox — the tool that sets up your AI coding environment inside Docker.

Skipped if they already exist.

Done!

Shows "All done!", prints your SSH key, and links to the GitHub setup page.

Mac — Quick install

Plain-language explanation

1. Developer tools (includes Git)

Installs Apple's command line tools. Includes Git for downloading project files. A popup from Apple may appear — completely safe.

Skipped if already installed.

2. Install Node.js

The engine that runs website code. Installed via Homebrew (Mac's app manager). If Homebrew isn't installed, it installs that first. May ask for your password.

Skipped if already installed.

3. Install OpenCode

The free AI coding assistant. You describe what you want, it writes the code.

Skipped if already installed.

4. Create SSH key

Digital ID card for your computer. Only the public half is shared.

Skipped if one exists.

5. Create Projects folder

~/Projects — where your websites will live.

Skipped if it exists.

Done!
